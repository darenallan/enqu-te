# Fiyen — validation du cahier des charges

Formulaire web qui permet au client de **valider, fonctionnalité par fonctionnalité**, le périmètre de la plateforme de livraison B2B Fiyen avant le développement.

## Contenu

- `index.html` : page unique (HTML, CSS et JavaScript intégrés) avec le formulaire de validation.

## Lancer

Ouvrir `index.html` dans un navigateur. Le projet Fiyen lui-même est dans le dépôt [`Fiyen`](https://github.com/darenallan/Fiyen).
